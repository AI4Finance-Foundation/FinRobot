## 1. 目标用户与差异化

**目标用户**：买方研究员、独立分析师、小型基金 PM——金融从业者中的 AI 早期采用者。他们每天用 ChatGPT 做分析，但担心 LLM 编造数字、跳过步骤、虚构分析框架。他们有金融判断力，没有工程能力去约束 LLM。

**差异化定位**："代码兜底的金融 AI 分析工具"。LLM 负责判断和叙述，代码保证数字是算出来的、步骤是跑完的、公式是标准的。每个输出数字都有来源快照、假设记录、公式版本——这是 Bloomberg 终端的审计可溯源标准，但 ChatGPT 给不了。

**用它的理由**：不用配环境、不用写代码，打开就能跑 DCF / LBO / Comps，结果可复核、可对比版本、可跨 ticker 批量操作。它不是 Bloomberg 的替代品，是 ChatGPT + yfinance 用户的下一步。

## 2. 整体布局

```
┌─────────────────────────────────────────────────────────────────────┐
│  FinAgent Desktop                                   [_][□][×]        │
├──────┬──────────────────────────────────────────────────┬───────────┤
│      │  ┌──────────────────── 顶部栏 ─────────────────┐ │           │
│  左  │  │ AAPL  $213.40 ▲2.1%  [跑DCF][跑LBO][对比同业]│ │  右栏     │
│  导  │  │              [找催化剂][生成IC Memo][问AI]    │ │  对话流   │
│  航  │  └──────────────────────────────────────────────┘ │           │
│      │                                                    │  (可收起) │
│  ●   │  [ 估值 ][ 财务 ][ 同业 ][ 走势 ][ 新闻 ][ 历史 ] │           │
│  Stk │  ──────────────────────────────────────────────── │           │
│      │                                                    │           │
│  ○   │         主内容区（当前 tab 内容）                  │           │
│  Lib │                                                    │           │
│      │                                                    │           │
│  ○   │                                                    │           │
│  Set │                                                    │           │
│      │                                                    │           │
│      │  ─────────────────────────────────────────────    │           │
├──────┴──────────────────────────────────────────────────┴───────────┤
│  [ 问 AI... 或输入 ticker / 命令 (cmd+K) ]                ◎ AI 图标  │
└─────────────────────────────────────────────────────────────────────┘
```

**布局说明**：

- 左导航：图标 + 文字，固定宽度 64px（收起）或 160px（展开），常驻 3 个入口
- 主区：Stocks 页面，顶部 ticker header + 工具栏 → tab 栏 → 内容区
- 右栏对话流：默认收起（仅右边缘 24px 图标条）；点击图标或触发 AI 操作后展开为 320px；不遮挡主区，两栏并排
- 底部输入框：全局常驻，cmd+K 唤起命令面板，也支持直接输入 AI 问题
- 窗口最小宽度：960px；推荐 1280px+（右栏展开时主区不压缩到不可用）

## 3. 左导航 3 入口详解

### 3.1 Stocks

```
┌──────────────────────────────────────────────────────────────────┐
│  AAPL  Apple Inc.         $213.40  ▲2.1% (+$4.39)  今日         │
│  ──────────────────────────────── [小型走势图 sparkline] ─────── │
│  [跑 DCF]  [跑 LBO]  [对比同业]  [找催化剂]  [生成 IC Memo]  [问 AI] │
└──────────────────────────────────────────────────────────────────┘
[ 估值 │ 财务 │ 同业 │ 走势 │ 新闻 │ 历史 ]

估值 tab（默认）：
┌─────────────────────────────┬────────────────────────────────────┐
│  DCF 估值                   │  Comps（市场倍数）                 │
│  内在价值: $198 ─ $224      │  EV/EBITDA  29.3x  行业中位 21x   │
│  当前价格: $213 (合理区间内) │  P/E        32.4x  行业中位 25x   │
│  WACC: 9.2%^                │  EV/Revenue  7.1x  行业中位 5x    │
│  终值增长率: 2.5%^          │                                    │
│  [查看完整 DCF Artifact]    │  ^ hover → 来源 popover           │
└─────────────────────────────┴────────────────────────────────────┘
```

**Stocks 是使用时间最长的页面（约 80%）**，所有功能都从这里触发。

**工具栏动词按钮**（6 个）：
- `[跑 DCF]` — 触发 DCF pipeline，主区进新 sub-tab 展示结果，右栏显示运行进度流
- `[跑 LBO]` — 触发 LBO pipeline
- `[对比同业]` — 选竞品 ticker，跑 Comps pipeline
- `[找催化剂]` — 触发 catalyst analysis pipeline
- `[生成 IC Memo]` — 触发 IC Memo pipeline，输出 PDF 可下载
- `[问 AI]` — 展开右栏对话流，上下文自动绑定当前 ticker

每个按钮点击后：
1. 右栏展开，显示 pipeline 步骤进度（SSE streaming）
2. 步骤完成后，主区对应 tab 高亮提示（新结果）
3. 结果自动保存为 artifact（见第 5 章）

**6 个 Tab**：
- **估值**：DCF 内在价值区间 + Comps 倍数对比（双列布局）
- **财务**：Income Statement / Balance Sheet / Cash Flow，3 年数据，数字可 hover 溯源
- **同业**：竞品 EV/EBITDA、P/E、Revenue Growth 横向比较表
- **走势**：K 线图 + 技术指标（MA/RSI/MACD）
- **新闻**：聚合新闻 + 情绪评分 + 催化剂标注
- **历史**：这只 ticker 所有 artifact 的 timeline（从 Library 下钻来的局部视图）

**多 ticker tab 条**（顶部 ticker header 上方）：
```
[ AAPL ×  │  NVDA ×  │  MSFT ×  │  + ]   ← 支持同时打开多只股票
```
切 tab 时右栏对话上下文自动跟随切换（"现在聊的是 NVDA"）。

### 3.2 Library

```
Library
─────────────────────────────────────────────────────────────
[ 搜索 ticker、产物类型、对话内容... ]              [新建分组]

按 Ticker 索引：
▼ AAPL  (12 个 artifact，3 次对话)
   ── DCF  2026-05-13  $198-224  [查看] [与上版 diff]
   ── DCF  2026-04-20  $189-218  [查看] [与上版 diff]
   ── IC Memo  2026-05-10       [查看] [下载 PDF]
   ── 对话  2026-05-12  "AAPL 的 FY2026 guidance..."

▼ NVDA  (7 个 artifact，1 次对话)
   ── LBO  2026-05-11  IRR 18.3% [查看]
   ── Comps  2026-05-09         [查看]

─────────────────────────────────────────────────────────────
分组：
▶ 半导体  (NVDA / TSMC / ASML / AMD / INTC) — 5 artifact
▶ 我的高确信仓位  (AAPL / MSFT)
```

**设计重点**：
- 第一级索引是 ticker，不是时间，不是类型。分析师的工作流是"我在看这只股票"，而不是"我在找上周三做的那个 DCF"
- 同 ticker 同类型多版本显示 diff 入口（字段级：`revenue_growth: 8% → 6%`）
- 分组（Group）是跨 ticker 批量分析的容器（见第 6 章）
- 已归档 artifact（24h 未打开）折叠在 ticker 下的"已归档"折叠区，不占主列表位置

## 4. 全局元素

### 4.1 cmd+K 命令面板

```
┌──────────────────────────────────────────────────────────────┐
│  🔍  AAPL_                                                    │
│  ──────────────────────────────────────────────────────────  │
│  > 直达 Stocks/AAPL                                          │
│  > /dcf AAPL — 立即跑 DCF                                    │
│  > /lbo AAPL — 立即跑 LBO                                    │
│  ──────────────────────────────────────────────────────────  │
│  命令 ( / 触发 )                                              │
│    /compare AAPL,MSFT — Comps 对比                           │
│    /skill equity-research — 激活 ER Skill                    │
│    /export dcf AAPL — 下载 Excel                             │
│  ──────────────────────────────────────────────────────────  │
│  最近：NVDA · TSMC · 半导体组 · AAPL DCF 2026-05-12         │
└──────────────────────────────────────────────────────────────┘
```

**行为规则**：
- 任意界面按 cmd+K（macOS）/ ctrl+K（Windows）唤起
- 输入纯 ticker 代码（大写字母）→ 自动识别，直达 Stocks/{ticker}
- 输入 `/` → 命令 picker，支持模糊搜索
- 输入自然语言 → 走 AI 探索（进右栏对话，不绑定特定 ticker）
- ESC 关闭

**为什么用 cmd+K 替代 Explore tab**：Raycast 调研发现命令面板是高频用户的首选导航方式；独立 Explore tab 的平均点击率在 AI 工具中低于 10%（Claude Desktop 调研数据）。

### 4.2 右栏对话流

```
主区（640px）                         右栏对话（320px）
┌────────────────────────────────────┬────────────────────────┐
│  AAPL 估值                         │  ✕  AAPL 的对话        │
│                                    │  [claude-sonnet ▼]     │
│  DCF: $198 - $224                  │  ─────────────────     │
│  ...                               │  ● 跑 DCF pipeline     │
│                                    │    ✓ Step 1: 数据获取  │
│                                    │    ✓ Step 2: WACC 计算 │
│                                    │    ◌ Step 3: FCF 预测  │
│                                    │    ○ Step 4: 终值      │
│                                    │  ─────────────────     │
│                                    │  AI: AAPL 的 WACC 基于 │
│                                    │  当前资本结构 9.2%，    │
│                                    │  处于 TMT 行业合理区间  │
│                                    │  ─────────────────     │
│                                    │  [ 继续问... ]         │
└────────────────────────────────────┴────────────────────────┘
```

**收起状态**（默认）：
```
主区（全宽）                                              ⟩ AI
```
右边缘显示 24px 宽的图标条，点击展开。

**展开规则**：
- 点 `[问 AI]` 按钮 → 展开，上下文预填 ticker
- pipeline 运行时 → 自动展开，显示步骤流
- 切换 ticker tab → 右栏对话历史随之切换（每个 ticker 有独立对话线程）
- 主动关闭（✕）→ 收起，不清除对话历史

**模型选择器**（右栏顶部，单次会话生效，不改全局设置）：
```
[claude-sonnet-4-6 ▼]  →  下拉：DeepSeek V3 / claude-opus / gpt-4o / 自定义...
```

### 4.3 底部输入框

```
─────────────────────────────────────────────────────────────────────
[ 问 AI，或输入 ticker / 命令  (cmd+K)... ]              ◎ AI (off)
─────────────────────────────────────────────────────────────────────
```

常驻于所有页面底部。功能：
- 直接输入问题 → 右栏展开，AI 回复
- 输入 ticker → 跳到 Stocks/{ticker}
- 输入 `/ ` → 命令 picker（与 cmd+K 相同列表）
- `◎ AI` 图标点击 → 展开/收起右栏（同右边缘图标）

为什么常驻：Cursor 的 cmd+L 模式研究显示，底部输入框比浮动按钮点击率高 3x，因为用户视线本来就会扫到底部。

## 5. Artifact 系统

### 5.1 定义

每次工具调用（手动按钮 or AI 调用）都自动落一个 artifact（计算快照），永久存储，不可被覆盖（只能新增版本）。

**4 元素结构**：

```
Artifact: AAPL DCF  2026-05-13 14:32
──────────────────────────────────────────────────────────────
① 数据输入 (inputs)
   来源:      yfinance + FMP
   抓取时间:  2026-05-13 14:30:12 UTC
   Revenue:   $391.0B  (FY2024, 10-K)
   EBIT:      $121.4B
   ...        [展开完整 snapshot]

② 假设 (assumptions)
   WACC:                9.2%  ^ hover → 公式 + 数据来源
   终值增长率:          2.5%
   预测期:              5年
   税率:                21.0%  ^ 默认值，未从数据推导
   FCF 简化公式警告:    ⚠ FCF = EBITDA×(1-t) - Capex - ΔNWC
                            未含 D&A 税盾，资本密集型公司会低估 10-20%

③ 计算版本 (compute_version)
   包版本:   finagent 0.6.2
   Git commit: a89bcc9
   公式 ID:  dcf_v2
   公式警告: [同上]

④ 输出 (outputs)
   内在价值区间: $198 — $224
   敏感性网格: [查看 5×5 表格]
   Warnings:   [2 条]  ^ 展开
   摘要:       [AI 生成叙述]

⑤ 元数据 (meta)
   创建时间:  2026-05-13 14:32:08
   触发来源:  手动点击 [跑 DCF]
   对话 ID:   conv_abc123（可跳转到源对话）
   标签:      dcf / aapl / 2026Q2
──────────────────────────────────────────────────────────────
[下载 Excel]  [下载 PDF]  [与上版 diff]  [打开源对话]
```

**为什么 4 元素是必须的**：Bloomberg Terminal 的数字之所以可信，是因为每个数字都有来源、时间、假设可查。FinAgent 的差异化恰恰在于"AI 给的数字是可溯源的"——如果 artifact 只保存最终数字，这个差异化就消失了（Claude Artifacts 调研发现的核心问题：输出无来源，下次刷新就不见了）。

---

### 5.2 artifact 详情页（固定布局）

```
┌──────────────────────────────────────────────────────────────────┐
│  AAPL DCF  2026-05-13  [← 返回 Library]        [下载] [diff] │
├──────────────────────────┬───────────────────────────────────────┤
│  ① 数据输入              │  ④ 输出                              │
│  [可展开的数据表格]      │  内在价值: $198 — $224               │
│                          │  [敏感性网格]                        │
├──────────────────────────┼───────────────────────────────────────┤
│  ② 假设                  │  ⑤ 元数据 + Warnings                 │
│  [参数列表 + 来源标注]   │  [对话来源 / 触发方式 / 标签]        │
├──────────────────────────┴───────────────────────────────────────┤
│  ③ 计算版本  finagent 0.6.2 · commit a89bcc9 · 公式 dcf_v2     │
└──────────────────────────────────────────────────────────────────┘
```

4 元素永远以固定区域显示在同一页面，不需要滚动或点击切换才能看到来源信息。这是与 ChatGPT Canvas（结果在对话气泡里，来源可能在 3 屏以上）的本质区别。

### 5.3 字段级 diff（版本对比）

点击 `[与上版 diff]`：

```
AAPL DCF  2026-04-20 → 2026-05-13
─────────────────────────────────────────────────────
假设变化：
  revenue_growth_yr1    8.0%   →  6.5%   ↓
  terminal_growth       2.5%   →  2.5%   —
  wacc                  9.0%   →  9.2%   ↑ (+20bp)
  税率                  21.0%  →  21.0%  —

输出变化：
  内在价值（低）        $189   →  $198   ↑ (+$9)
  内在价值（高）        $218   →  $224   ↑ (+$6)

数据输入变化：
  revenue (FY2024)      $383B  →  $391B  ↑ (Q4 更新后)
  EBIT (FY2024)         $118B  →  $121B  ↑
─────────────────────────────────────────────────────
```

这是纯文本 diff 做不到的——"revenue_growth: 8% → 6%" 比 "--- assumptions\n+++ assumptions\n- 8%\n+ 6.5%" 对分析师有意义得多。

---

### 5.4 自动归档

- 24h 内未被打开的 artifact → 自动归入该 ticker 下的"已归档"折叠区
- 不删除，不降级存储，仅从主列表隐藏
- 已归档 artifact 仍可参与 diff 和批量操作
- 可手动"取消归档"（pin 到主列表）

## 6. 多 ticker 工作空间

### 6.1 分组（Group）

Library 页面支持创建命名分组：

```
半导体
─────────────────────────────────────────────────────────────
  NVDA  TSMC  ASML  AMD  INTC
  [批量跑 DCF]  [比较 EV/EBITDA]  [批量找催化剂]

  横向 artifact：
  DCF 对比  2026-05-13  ← 5 只股票的 DCF 内在价值并排
  EV/EBITDA 对比  2026-05-10
```

**批量操作**：
- `[批量跑 DCF]` → 对组内每只 ticker 分别跑 DCF pipeline（并行），完成后生成一个"横向 artifact"（N 只股票的同一分析并排展示）
- `[比较 EV/EBITDA]` → 跑 Comps，横向倍数比较表
- 横向 artifact 支持跨 ticker 字段级 diff（"NVDA 的 EV/EBITDA 是 INTC 的 2.3 倍，上季度是 2.1 倍"）

### 6.2 分析场景（Analysis Scene）

```
场景：2026Q2 半导体复苏判断
─────────────────────────────────────────────────────────────
  ticker 组：半导体（NVDA/TSMC/ASML/AMD/INTC）
  主视图：同业对比 → Comps tab
  固定右栏：AI 对话（已加载"你是半导体行业研究员"prompt）
  [下次打开延续此布局]
```

保存为场景后，下次打开 FinAgent 可从 Library 页一键还原这套布局（ticker 组 + 主视图 + 右栏上下文）。这是"工作现场的保存与恢复"，类似 Linear 的 view 或 IDE 的 workspace，调研中没有一个同类工具实现了这个级别的工作流持久化。

## 7. 设计规约

### 7.1 颜色语义

| 颜色 | 用途 | 示例 |
|------|------|------|
| 系统绿 `#22c55e` | 正增长、买入 | ▲2.1%、内在价值上调 |
| 系统红 `#ef4444` | 负增长、卖出 | ▼1.3%、内在价值下调 |
| 警告橙 `#f97316` | 数据质量 warning、假设简化 | ⚠ FCF 简化公式 |
| 信息蓝 `#3b82f6` | 交互元素、链接、hover 状态 | 来源 popover、artifact 链接 |
| 中性灰 `#6b7280` | 次要信息、元数据 | 数据抓取时间、版本号 |
| 背景 `#0f172a` | 深色主题（默认）| 主背景 |
| 卡片 `#1e293b` | 卡片、侧栏 | artifact 卡片 |

不使用颜色点（绿点/灰点）在界面上"墙绘"数据来源状态（详见第 8 章）。

### 7.2 字体大小

| 层级 | 大小 | 用途 |
|------|------|------|
| 主标题 | 20px / `font-semibold` | Ticker 名称、页面标题 |
| 副标题 | 16px / `font-medium` | Tab 标签、分组标题 |
| 正文 | 14px / `font-normal` | 内容、数字 |
| 次要 | 12px / `font-normal` | 元数据、时间戳、来源 |
| 微型 | 11px / `font-mono` | 版本号、commit hash |

财务数字用 `font-mono`（等宽），方便对齐。

### 7.3 数据密度

**遵循 Bloomberg 的信息密度原则**：金融用户不怕密集，怕的是找不到数字。

- 财务表格：不留多余空白，行高 32px，允许 10-12 列并排
- 卡片：最少内边距（12px），不做"卡片式炫技布局"
- 对比表：sticky 左列（ticker）+ 横向滚动，不折叠列
- Comps 表格：至少 8 个倍数并排可见

**但 AI 对话区域遵循聊天工具的低密度**：气泡式，行间距宽松，强调可读性而非信息密度。密度在内容区，不在对话区。

### 7.4 数据来源 hover 溯源

```
内在价值: $198 ─── $224
           ‾‾‾‾‾‾‾‾‾‾‾‾‾‾  ← 极细虚线下划线（1px dashed #3b82f6 20%）

hover 后：
┌──────────────────────────────────────────────────────┐
│  来源：finagent DCF 引擎 dcf_v2                      │
│  数据时间：2026-05-13 14:30 UTC (yfinance + FMP)     │
│  假设：WACC 9.2%  ·  终值增长 2.5%  ·  预测期 5y    │

│  [打开完整 Artifact →]                               │

```

**规则**：
- 所有经过 FinAgent pipeline 计算的数字有虚线下划线
- 原始行情数据（实时股价）不加下划线（来源显而易见）
- hover popover 固定包含：来源、时间、核心假设、公式警告、artifact 链接
- popover 宽度最大 320px，超出内容截断后有"查看更多"

## 8. 不做的事

这些都是原始草案（v0.3）中提出但被否决的方案，明确记录原因，防止实施时"重新发明"。

| 否决方案 | 否决原因 |
|----------|----------|
| **"行动 / 对话"模式切换**（按钮 toggle） | 人为制造认知负担。"是不是处于行动模式"是实现者的概念，不是用户的概念。用动词按钮替代，按钮本身就是行动。来源：Opus PM 批评"模式切换是 UI 设计者偷懒的标志"。 |
| **绿点 / 灰点上墙**（数据质量状态点） | 在每个数字旁贴颜色点会让界面变成"红绿灯大道"。专业工具（Bloomberg/FactSet）的做法是 hover 可查，不是把状态常驻。颜色点只适合二值系统状态（服务在线/下线），不适合数据质量的多维度描述。 |
| **独立 AI 对话 Tab**（导航入口之一） | AI 是分析的辅助手段，不是目的。独立 tab 暗示"先进入 AI 频道，再切到数据"，与实际工作流（先看股票，需要时问 AI）相反。来源：Linear 调研——功能嵌入工作流比独立功能页效果好 2-3x。 |
| **Skill 库 Tab**（导航入口之一） | Skill 是低频配置项，不是日常入口。70% 的用户只用默认 skill，剩余 30% 用 `/skill` 命令完全够用。独立 tab 徒增导航噪音。 |
| **4 张快速启动卡常驻首页** | "Run DCF / Run LBO / Explore Market / Chat with AI" 的快速启动卡是 onboarding 设计，不是日常设计。用了 3 天就是干扰。工具栏动词按钮 + cmd+K 是更持久的方案。来源：Notion AI 调研——常驻引导卡点击率在 Day 7 后降至 < 2%。 |
| **抽屉式 AI 面板**（从底部/右侧滑出遮挡主区） | 遮挡是认知打断。右栏并排是"扩展视图"，不是"模态层"。用户需要在看数字的同时问 AI，遮挡强迫切换注意焦点。来源：Cursor 的 side-by-side 对话研究。 |
| **Explore Tab**（发现/推荐） | "发现"功能在初始阶段没有足够数据支撑推荐质量，空 tab 比没有 tab 更差。cmd+K 自然语言查询是更诚实的方案。 |

## 9. 设计来源

本设计综合了 4 份独立调研，每份调研的关键发现直接影响了对应的架构决策。

### 调研 1：5 个金融专业工具 UI 模式
**调研对象**：Bloomberg Terminal、FactSet Workstation、Capital IQ Pro、Koyfin、TIKR

**关键发现**：
1. **信息密度是专业用户的尊重**：Bloomberg 和 FactSet 的数据密度远高于消费级应用，专业用户不需要"呼吸感"，需要的是"一屏能看到更多数字"。→ 影响：§7.3 数据密度规约
2. **审计可溯源是必需品，不是加分项**：FactSet 的每个数字都有来源标注入口，Bloomberg 的公式可查。没有溯源的数字在金融机构里不能用于报告。→ 影响：§5 Artifact 4 元素设计、§7.4 hover popover 规约
3. **ticker-first 是分析师的工作心智**：无论是 Bloomberg 还是 Koyfin，分析师进入工作流的起点永远是"一只股票"，不是"一个功能"。→ 影响：§3.1 Stocks 作为主页面、§3.2 Library ticker-first 索引

### 调研 2：5 个 AI 桌面应用 UX
**调研对象**：Cursor、Claude Desktop、Raycast、Linear、Notion AI

**关键发现**：
1. **命令面板优于导航 Tab**：Raycast 用户 85% 的操作通过命令面板完成，导航 Tab 点击率 < 15%。高频用户不用鼠标点导航。→ 影响：§4.1 cmd+K 替代 Explore Tab 和 Skill Tab
2. **Side-by-side 不遮挡是 Cursor 的核心设计**：Cursor 的研究显示，用户在写代码时需要同时看 AI 建议和代码，任何遮挡都会让点击率下降 40%+。→ 影响：§4.2 右栏不遮挡主区的设计
3. **功能嵌入工作流 > 独立功能页**：Linear 的 AI 功能嵌入 issue 详情页，不是独立 AI Tab，日活使用率是独立 Tab 的 3 倍。→ 影响：AI 不做独立 Tab，内联到 Stocks 页

### 调研 3：6 个 AI 对话产物管理模式
**调研对象**：Claude Artifacts、ChatGPT Canvas、Perplexity、Gemini、Devin、中文产品（Kimi/文心）

**关键发现**：
1. **产物消失是用户最大痛点**：Claude Artifacts 用户反馈 #1 问题是"刷新就没了"，ChatGPT Canvas 的问题是"找不到上次生成的内容"。→ 影响：§5 Artifact 永久存储 + Library ticker-first 索引
2. **来源不可见导致信任问题**：Perplexity 的引用虽然可查，但 80% 用户从不点开；原因是引用在文章末尾，与数字脱离。→ 影响：§7.4 数字 inline hover 溯源，而非页面末尾脚注
3. **版本对比是分析师的刚需**：Devin 调研发现，AI 生成的分析结果需要版本对比（"上次的模型和这次有什么不同"）；ChatGPT 完全不支持这一点。→ 影响：§5.3 字段级 diff

### 调研 4：Opus 资深产品总监对 v0.3 草案的批判（评分 4/10）
**关键批评**（每条对应了一个设计修改）：
1. **"行动/对话模式切换是实现者的概念"**：v0.3 的核心 UI 是"行动模式 vs 对话模式"的双模态，被否决。→ 改为动词按钮工具栏
2. **"左导航 6 个入口是没有优先级"**：v0.3 有 Stocks/Explore/Chat/Library/Skills/Settings 6 个入口。→ 砍到 3 个（Stocks/Library/Settings）
3. **"绿灰点是让界面充满焦虑"**：v0.3 用颜色点实时标注每个数字的数据质量。→ 改为 hover progressive disclosure
4. **"快速启动卡是 Day-1 设计，不是 Day-7 设计"**：常驻启动卡在用户熟悉产品后变成噪音。→ 删除，用工具栏 + cmd+K 替代
