## Task 2: Resolve Research vs DCF Pipeline Overlap

**Files:**
- Modify: `finrobot/engine/pipelines/equity_research.py:200-248`
- Modify: `desktop/src/stores/appStore.ts` (store DCF result from Research)
- Modify: `desktop/src/views/TickerWorkspace.tsx` (after Research completes, populate dcfResult)

**Problem:** `equity_research.py:_execute_financial_modeling()` calls `calculate_dcf()` internally (line ~215). When user runs Research then DCF separately, they get two different DCF results (different LLM-selected assumptions each time) with no explanation.

**Solution:** When Research pipeline completes, its DCF result is stored in the same `dcfResult` slot in the store. User sees Research DCF result in Valuation tab immediately. If they run standalone DCF pipeline, it OVERWRITES with new assumptions (explicit user action).

- [ ] **Step 1: Ensure Research pipeline returns DCF result in structured output**

Read `finrobot/engine/pipelines/equity_research.py` around line 200-248. Verify that `_execute_financial_modeling()` returns `DCFResult` in `StepOutput.structured`. If it does, no backend change needed. If not, modify to include it:

```python
# In _execute_financial_modeling(), ensure the return includes DCF result
return StepOutput(
    text=narrative,
    structured=dcf_result,  # DCFResult object
)
```

- [ ] **Step 2: Frontend — extract DCF result from Research pipeline completion**

In the SSE completion handler (likely in `PipelineRunner.tsx` or the SSE hook), when `research` pipeline completes:

```typescript
// After research pipeline completes, check if structured output contains DCF result
if (pipelineType === 'research' && result?.steps?.financial_modeling?.structured) {
  const dcfFromResearch = result.steps.financial_modeling.structured
  if (dcfFromResearch?.implied_share_price != null) {
    useAppStore.getState().setDcfResult(dcfFromResearch)
  }
}
```

This means: after running Research, the Valuation tab is automatically populated with the Research's DCF result. User doesn't need to run DCF separately unless they want fresh assumptions.

In `desktop/src/views/ValuationTab.tsx`, add a subtle indicator showing where the DCF result came from:

