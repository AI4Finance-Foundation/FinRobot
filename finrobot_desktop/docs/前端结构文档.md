## 0. 顶层架构

### 0.1 进程拓扑（桌面运行时三进程）

```
┌───────────────────────────────────────────────────────────┐
│  Tauri Rust 进程  (src-tauri/src/main.rs → lib.rs::run)   │
│  ├─ 拥有 main 窗口（1200×800，Overlay 标题栏）            │
│  ├─ 5 个 plugin：shell / dialog / fs / global-shortcut /  │
│  │                log（lib.rs:21-31）                     │
│  └─ tauri-plugin-shell `sidecar.rs::spawn_and_wait_for_  │
│     ready` 启二进制 ↓                                     │
│  ┌───────────────────────────────────────────────────────┐│
│  │ Python FastAPI sidecar (binaries/finrobot-server)     ││
│  │ 监听 127.0.0.1:8321；poll /health 200 后才 show 窗口  ││
│  └───────────────────────────────────────────────────────┘│
│  ┌───────────────────────────────────────────────────────┐│
│  │ WebView (React app)                                   ││
│  │ devUrl: http://localhost:5173                         ││
│  │ frontendDist: ../ui/dist                              ││
│  │ ── fetch / EventSource → 127.0.0.1:8321 ───────────→  ││
│  └───────────────────────────────────────────────────────┘│
└───────────────────────────────────────────────────────────┘
```

**关键设计：UI ↔ Rust 不走 `invoke` RPC，全部走本地 HTTP/SSE。** Rust 层 `#[tauri::command]` 数量 = 0（`src-tauri/src/lib.rs:12` 注释：`Communication is plain HTTP/SSE. No 'invoke()' calls into Rust.`）。`ui/src/lib/tauri.ts` 仅暴露 plugin wrappers。

### 0.2 App 组件树

```
main.tsx (StrictMode)
└─ QueryClientProvider (queryClient)
   └─ RouterProvider (router)
      └─ AppShell  (layout/AppShell.tsx)
         ├─ TitleBar         (layout/TitleBar.tsx)      — Overlay 标题栏内容条
         ├─ Sidebar          (layout/Sidebar.tsx)        — 200 px 左侧导航 + watchlist
         ├─ <Outlet />       ← 6 个 Page
         ├─ RightChatPanel   (layout/RightChatPanel.tsx) — Vercel AI SDK /chat
         ├─ CmdKOverlay      (layout/CmdKOverlay.tsx)   — 全局 Cmd+K
         └─ StatusBar        (components/StatusBar.tsx) — 底部状态条
```

`main.tsx` 还导入字体：`@fontsource/dm-sans` (400/500/600/700) + `jetbrains-mono` (400/500/600/700) + `fraunces` (400/500/600)。

### 0.3 状态管理拆分

- **全局 UI 状态**：5 个 Zustand store（`stores/` 详见 §9）
- **Server 状态**：TanStack Query（`api/queryClient.ts`）—— `staleTime: 5 min`，`retry: 1`，`refetchOnWindowFocus: false`（本地 app，不必要）
- **本地组件状态**：`useState/useReducer`
- **i18n 偏好**：Zustand + `persist(localStorage, 'finrobot-ui-prefs')`，默认 `zh`

### 13.1 Rust 文件

#### `src-tauri/src/lib.rs` — Tauri builder 完整逻辑

```
pub fn run():
  // 1) 构建 builder：装 4 个基础 plugin
  let mut builder = tauri::Builder::default()
    .plugin(tauri_plugin_shell::init())
    .plugin(tauri_plugin_dialog::init())
    .plugin(tauri_plugin_fs::init())
    .plugin(tauri_plugin_log::Builder::default()
              .level(log::LevelFilter::Info).build());

  // 2) 桌面端追加 global-shortcut（移动端不可用）
  #[cfg(desktop)]
  builder = builder.plugin(tauri_plugin_global_shortcut::Builder::new().build());

  // 3) setup 钩子：spawn sidecar
  .setup(|app| {
    let handle = app.handle().clone();
    tauri::async_runtime::spawn(async move {
      // sidecar 的 spawn + poll 是同步阻塞操作，
      // 用 spawn_blocking 卸到线程池，避免阻塞 Tauri 事件循环
      match tauri::async_runtime::spawn_blocking(move ||
              sidecar::spawn_and_wait_for_ready(&handle)).await
      {
        Ok(Ok(_child)) => eprintln!("[desktop] sidecar ready — window will load the UI"),
        Ok(Err(e))    => { eprintln!("[desktop] fatal: sidecar failed to start: {e}");
                            std::process::exit(1); }
        Err(e)        => { eprintln!("[desktop] fatal: join error: {e}");
                            std::process::exit(1); }
      }
    });
    Ok(())
  })
  .run(tauri::generate_context!())
  .expect("error while running tauri application");
```

**错误处理**：sidecar 启动失败 → `std::process::exit(1)`。`spawn_blocking` join 失败也直接 exit 1。

**生命周期注意**：`Ok(Ok(_child))` 分支故意 `drop` 掉 `CommandChild` 句柄——sidecar 进程会在 Tauri 退出时被 OS 杀掉。注释里写 `Phase 4c` 才会做显式 cleanup。

`#[cfg_attr(mobile, tauri::mobile_entry_point)]` 标注让同一份代码可在移动端复用。

#### `src-tauri/src/sidecar.rs` — `spawn_and_wait_for_ready` 完整逻辑

签名：

```
pub fn spawn_and_wait_for_ready(app: &AppHandle)
    -> Result<tauri_plugin_shell::process::CommandChild, String>
```

执行步骤：

1. **spawn**：`app.shell().sidecar("finrobot-server")` 通过 platform-triple 找二进制（例：`finrobot-server-aarch64-apple-darwin`），传参 `["--host", "127.0.0.1", "--port", "8321"]`，调 `.spawn()`，错误转字符串
2. **日志转发**：起一个 async task 消费 `rx: Receiver<CommandEvent>`：
   - `Stdout(bytes)` → `eprintln!("[sidecar] {}", line)`
   - `Stderr(bytes)` → `eprintln!("[sidecar:err] {}", line)`
   - `Error(msg)`   → `eprintln!("[sidecar:error] {msg}")`
   - `Terminated(payload)` → 打印退出码并 `break`
3. **health poll**：用 `ureq::get` 同步 HTTP（**不依赖 tokio**），每 500 ms 试一次，单次超时 2 秒，**总超时 30 秒**（`Duration::from_secs(30)`）。命中 `200` 返 `Ok(child)`；超时返 `Err("sidecar did not become ready within 30 seconds")`

**为什么用 ureq + thread**：Tauri 启动阶段，async 运行时还没完全就绪；`ureq` 是纯阻塞 HTTP 库，配合 `spawn_blocking` 干净规避竞态。
