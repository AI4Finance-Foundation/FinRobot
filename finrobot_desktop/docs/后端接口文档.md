## 0. FastAPI app 启动顺序与状态

`finrobot/server.py:148` `app = FastAPI(title="FinRobot", lifespan=lifespan)`。`lifespan`（`server.py:79`）启动顺序：

1. `secret_store = create_secret_store()` — keychain 或文件后端（`finrobot/secret_store.py`）
2. `settings = get_settings()` — 从 `~/.finrobot/settings.json` + env + keychain 合成 `FinRobotSettings`（`config.py`）
3. `data_layer = build_data_layer(settings)` — 按 capabilities 链式接入 provider（`data_layer_factory.py`）
4. `skill_runtime = build_skill_registry()` —— 加载 `.claude/skills/*.md` 元数据（`engine/skills/registry.py`）
5. `deps = FinRobotDeps(...)`（`engine/deps.py`），封装 `data_layer / settings / report_cache / skill_runtime`
6. `agent = create_lead_agent(deps)`（`engine/orchestrator.py:create_lead_agent`）— PydanticAI Lead Agent + 6 个工具
7. `sub_agents = create_sub_agents(...)`（`engine/agents/factory.py`）—— 5 个子 Agent（见 §16）
8. `artifact_store = ArtifactStore()`（`artifact/store.py`）落地 `~/.finrobot-desktop/artifacts/`
9. `run_store = RunStore()`（`run_store.py`）SQLite 持久化 run 历史
10. 后台 task：`_archive_stale_background()` → `artifact_store.archive_stale(hours=24)`（`server.py:120`）
11. **CORS middleware**（`server.py:152-158`）只放行 `http://localhost:5173` 和 `http://127.0.0.1:5173`
12. **挂载 14 个 router**（`server.py:159-173`）+ 6 条直挂在 `app` 上的顶层路由

`app.state` 关键字段（`server.py:106-115`）：`agent / deps / secret_store / settings_path / run_store / run_tasks / artifact_store / transcript_writers / sub_agents`。

Shutdown：取消所有 `run_tasks` → `await gather(return_exceptions=True)` → `run_store.close()` → flush 所有 `transcript_writers`（`server.py:129-145`）。

## 20. `engine/agents/` + `engine/orchestrator.py` — PydanticAI 层

`engine/orchestrator.py`：
- `create_lead_agent(deps)` — 主 Agent + 6 tool（estimate_wacc / run_dcf / run_lbo / run_comps / search_skills / register_skill via mcp）

- `_collect_warnings` — 抽 PipelineResult 的 validator 警告

`engine/agents/factory.py`：`create_sub_agents(settings, skill_registry)` → 5 个 sub-agent。每个 agent 的系统指令存为独立 markdown 文件，下面给出指令要点（**文件本身就是 prompt，编辑即上线**）：

#### `data_agent.md` — 数据采集
- 角色：金融数据采集专员，**只采不分析**
- 单 ticker：拉 financials / price / news + 来源 + 时间戳，标记缺失/可疑数据
- 多 ticker：从 context 抽全部 ticker，**逐个**调 `query_financial_data`，独立 section 输出
- 硬约束：始终用 `query_financial_data` 工具，**禁止编造数字**

#### `analysis_agent.md` — 同业分析
- 角色：股权研究分析师，**专攻 peer / comps**
- 输出：3-5 个 peer + 选择理由 / 经营指标对比（增长、毛利、ROE）/ 估值倍数对比（EV/EBITDA, P/E, EV/Revenue）/ 相对溢价折价说明 / 可比性调整
- 如果 context 提供 skill 方法论，遵循其框架与术语

#### `modeling_agent.md` — 估值建模
- 角色：金融建模专家
- 输出：3-5 年营收/EBITDA/FCF 预测 + 明确假设（增长、margin、capex）/ WACC（含 risk-free / beta / ERP / cost-of-debt）/ 终值用两法（永续增长 + 退出倍数）/ 隐含价区间 + 敏感性 / **所有关键计算可追溯**
- 如有 skill 方法论，遵循

#### `synthesis_agent.md` — 投资 thesis 合成
- 角色：投资策略师
- 输出：明确推荐（Buy/Hold/Sell）/ 3-5 个 catalysts / 3-5 个 risks / 市场误价点 / 引用前序数据点不新增 / 价格目标 + 时间窗 + 方法
- 语言：遵循 step prompt，默认英文；**不混用语言**

#### `report_agent.md` — 报告编排
- 角色：金融报告编辑，**只组织不分析**
- 输出：Markdown 结构 + 执行摘要在前（推荐/目标价/关键指标）+ 标准段落（Company Overview / Financial Summary / Peer Analysis / Valuation / Investment Thesis / Risks / Appendix）+ 表格 / 数字跨段一致 / 简洁专业无填充
- 硬约束：**禁止新增分析**，仅组织前序结果；语言遵循 step prompt，默认英文，不混用

`engine/deps.py`：`FinRobotDeps` 数据类，注入到 PydanticAI `RunContext`（包含 `data_layer / settings / report_cache / skill_runtime`）。

## 42. 横切关注点

- **认证**：无（仅本地开发，公网部署需加 middleware）
- **CORS**（`server.py:154`）：仅放行 `http://localhost:5173` + `http://127.0.0.1:5173`（Tauri 包装 WebView 走 `file://` → 不触发 CORS）
- **错误码约定**：
  - 422 — Pydantic 校验失败 / `ValueError`
  - 404 — 资源不存在（artifact / run / ticker 数据缺失 / 10-K 无内容）
  - 502 — `ProviderError`（数据源拒接）
  - 500 — 未预期 `RuntimeError / OSError`
  - 501 — 可选依赖未装（`backtrader` / `weasyprint`）
  - 503 — `app.state` 未初始化（lifespan 没跑完）
- **审计链**：`/chat` 流被 `_intercept_native_events` 镜像到 `TranscriptWriter`，每 session 独立 JSONL
- **后台任务**：startup `archive_stale(hours=24)`；run pipeline 走 `asyncio.create_task` 注册到 `app.state.run_tasks`，shutdown 时 `cancel + gather(return_exceptions=True)`
- **持久化路径**：
  - 设置：`~/.finrobot/settings.json`
  - Secrets：macOS keychain（dev mode 落地文件）
  - Sessions：`~/.finrobot-desktop/sessions/<id>.jsonl`
  - Artifacts：`~/.finrobot-desktop/artifacts/<ticker>/<id>.json` + `index.json`
  - Runs：SQLite（`RunStore` 默认路径）
  - Journal：SQLite（`JournalStore` 默认路径）
  - Data cache：SQLite（`_default_cache_db_path()`）

## 43. 架构红线（机械强制：`pytest tests/audit/test_architecture.py`）

1. `compute/` 和 `models/` 是**叶子层** — 不 import `agents/pipelines/orchestrator/LLM 库`

4. 依赖黑名单：**禁用** LangChain / LangGraph / AutoGen / LiteLLM；**PydanticAI only**
