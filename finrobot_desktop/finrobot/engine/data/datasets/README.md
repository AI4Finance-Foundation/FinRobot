# Damodaran Industry Datasets

DCF input fallback when ticker-level data is missing — keyed on yfinance
`industry` strings, with `industry_defaults.py` doing the lookup.

`industry_medians.csv` is the runtime artifact — `industry_defaults.py` loads
it and never touches the raw xls files. Keep the xls files in-repo so the CSV
is reproducible.

## Updating

Damodaran refreshes datasets twice a year (Jan + Jul). To refresh:

```bash
cd finrobot/engine/data/datasets

# 1. Download the new xls files (rename TAG to the new date)
for n in capex margin taxrate betas; do
  curl -sLo damodaran_${n}_YYYY-MM.xls \
    https://pages.stern.nyu.edu/~adamodar/pc/datasets/${n}.xls
done

# 2. Update TAG constant in build_industry_medians.py

# 3. Regenerate the CSV
uv run python build_industry_medians.py

# 4. Verify against last release
git diff industry_medians.csv | head

# 5. Re-run the test suite — schema regressions surface in test_industry_defaults.py
uv run pytest tests/unit/test_industry_defaults.py -v
```

## Derived ratios in `industry_medians.csv`

| Field | How it's computed |
|---|---|
| `capex_pct_revenue` | `Net Cap Ex/Sales + da_pct_revenue` (CapEx = NetCapEx + Depreciation) |
| `da_pct_revenue` | `EBITDA/Sales − Pre-tax Unadjusted Operating Margin` (Op Income = EBITDA − D&A) |
| `ebitda_pct_revenue` | EBITDA/Sales (direct from margin.xls) |
| `effective_tax_rate` | "Aggregate tax rate" across money-making firms (taxrate.xls, accrual basis) |
| `levered_beta` | Equity beta (raw, levered) — from the 5y average in betas.xls |
| `debt_equity` | Industry-average D/E ratio (betas.xls) |

All values are clipped to DCF-sane ranges (e.g. tax 5–40%, beta 0.3–2.5) in
the build script. See header comment in `build_industry_medians.py`.

## Why xls files instead of just the CSV?

Damodaran publishes xls only — the CSV is our derived artifact. Keeping the
raw files in-repo means:

1. The CSV is **reproducible** from primary sources.
2. Reviewers can audit which column we used (e.g. accrual vs cash tax rate).
3. Future refreshes can diff the xls files first to spot Damodaran schema
   changes before re-running the build script.

The four xls files total ≈230 KB — tolerable.
