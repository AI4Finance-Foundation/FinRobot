# P1.5 Spec — Financial Computing Core

## Goal

Replace free-text string passing between pipeline steps with structured Pydantic data models, and add real financial calculation functions (WACC, DCF present value, comps multiples) implemented in code. After P1.5, the LLM's role is reduced to "select parameters + write narrative" while code handles all deterministic math.

This is the phase that gives FinAgent irreplaceable value. Without it, the project is a prompt wrapper.

## Status: 🔄 In Progress

## The Problem Being Solved

Before P1.5, pipeline steps pass `str` (LLM free-text) to each other. This means:
- Financial numbers are embedded in prose, extracted by the next LLM "reading" the text
- Numerical precision is lost (LLM might round, hallucinate, or misquote earlier numbers)
- Validators can only check keywords, not values
- There is zero code logic that couldn't be replaced by a single well-prompted LLM call

After P1.5:
- Pipeline steps pass typed Pydantic models (FinancialData, PeerComps, DCFResult, etc.)
- Financial calculations (WACC, DCF NPV, multiples) are deterministic code — same inputs always produce same outputs
- Validators check numerical reasonableness (WACC in 3-25% range, PE > 0, etc.)
- The LLM cannot skip or fake calculations — code runs the math, LLM provides judgment

## Acceptance Criteria

All must pass:

1. `finagent research AAPL` → pipeline steps pass typed Pydantic models, not strings. Verified by log output: `logger.info(f"Step '{step.name}' produced structured data: {type(model).__name__}")` emitted for each step that returns a StepOutput with structured data.
2. DCF calculation: given the same inputs (revenue, growth rate, WACC, terminal growth), code produces the **exact same** implied price every time. Test this with deterministic unit tests — no LLM involved.
3. WACC calculation: `calculate_wacc(risk_free_rate=0.04, beta=1.2, equity_risk_premium=0.05, cost_of_debt=0.04, tax_rate=0.21, debt_ratio=0.3)` returns a deterministic float. Unit test verifies against hand-calculated answer.
4. Comps multiples: given financial data for 3 companies, code calculates EV/EBITDA, P/E, EV/Revenue and returns a structured table with median/mean. Unit test with known inputs/outputs.
5. Validators check numerical values: `validate_dcf_result(DCFResult(wacc=-0.05, ...))` → fails with "WACC must be positive". Not keyword search.
6. `python -m pytest tests/ -x -v --tb=short --ignore=tests/integration` — all tests pass, including deterministic financial calculation tests.
7. Quality comparison: `finagent research AAPL` output now contains **code-computed numbers** (exact, reproducible) rather than LLM-hallucinated calculations.

## Key Design Decisions

| Decision | Choice |
|---|---|
| Step data passing | Typed Pydantic models, not str. Pipeline stores both str (for report) and typed model (for next step). |
| Financial math | Deterministic pure Python functions, not LLM. No numpy dependency. |
| LLM role in pipeline | Select parameters + write narrative, not calculate |
| FCF formula | Simplified: `EBITDA × (1 - tax) - revenue × capex_pct - revenue × nwc_pct`. Note: this over-taxes by not deducting D&A before tax. Acceptable simplification for P1.5 since yfinance doesn't provide D&A separately. Add `depreciation` field to DCFInputs in P2a when FMP provides it. |
| Pydantic mutability | All models use `model_config = ConfigDict(frozen=False)` to allow compute functions to fill derived fields. Alternative (model_copy) creates unnecessary object churn. |
| LLM → structured data bridge | modeling_agent outputs JSON via PydanticAI structured output (Agent with `output_type=DCFInputs`). No manual JSON parsing. |
| NPV calculation | Manual: `sum(fcf / (1 + wacc) ** (i+1) for i, fcf in enumerate(fcfs))`. Pure Python, no numpy. |
| Model layer validation vs business validation | Pydantic Field constraints (ge, le) catch obviously invalid data at construction. Business validators (validate_dcf_result) check domain-specific reasonableness (WACC 3-25%). Both layers serve different purposes. |
| Sensitivity WACC override | `calculate_dcf` accepts `wacc_override: float | None` and `tg_override: float | None` — direct override, no back-solving for risk_free_rate. |
| StepOutput.structured typing | Uses `Any` (not `BaseModel`) for the structured field to avoid serialization issues. Runtime isinstance checks enforce correctness. JSON roundtrip of PipelineResult is a known limitation — in-memory only for P1.5. |

### File 31: `finagent/engine/models/financial.py`

**Purpose**: Pydantic models for structured financial data. These replace `str` as the data type passed between pipeline steps.

**What this code does that raw LLM cannot**: Enforces data schema. A FinancialData object MUST have revenue as a float, MUST have margins as percentages. LLM free-text can omit fields, use wrong units, or hallucinate numbers. Typed models prevent all of this.

```python
from typing import Any
from pydantic import BaseModel, ConfigDict, Field
from datetime import datetime

class FinancialData(BaseModel):
    """Structured financial data for a single company."""
    model_config = ConfigDict(frozen=False)  # allow compute functions to fill derived fields
    
    ticker: str
    timestamp: datetime
    
    # Income statement
    revenue: float = Field(description="Annual revenue in USD")
    ebitda: float = Field(description="EBITDA in USD")
    net_income: float = Field(description="Net income in USD")
    
    # Balance sheet (needed for EV calculation)
    total_debt: float = Field(default=0, description="Total debt in USD")
    total_cash: float = Field(default=0, description="Total cash in USD")
    
    # Margins (as decimals, e.g. 0.47 = 47%)
    gross_margin: float = Field(ge=0, le=1, description="Gross margin as decimal")
    operating_margin: float = Field(ge=-5, le=1, description="Operating margin as decimal, ge=-5 to accommodate early-stage/biotech")
    
    # Valuation
    market_cap: float = Field(description="Market cap in USD")
    shares_outstanding: float = Field(gt=0)
    current_price: float = Field(gt=0)
    pe_ratio: float | None = Field(default=None, description="P/E ratio, None if negative earnings")
    
    # Derived (computed by code, not LLM)
    enterprise_value: float | None = Field(default=None, description="EV = market_cap + total_debt - total_cash")
    ev_ebitda: float | None = Field(default=None, description="EV/EBITDA multiple")
    ev_revenue: float | None = Field(default=None, description="EV/Revenue multiple")
    
    # Price history summary
    price_52w_high: float | None = None
    price_52w_low: float | None = None
    
    # Metadata
    data_source: str = "yfinance"
    warnings: list[str] = Field(default_factory=list)

    """Structured price history."""
    ticker: str
    period: str  # e.g. "1y"
    data_points: int

    low_52w: float

    mean_pe: float | None = None

class PeerSelection(BaseModel):
    """LLM structured output for peer selection step.

    Used with output_type=PeerSelection in _execute_peer_analysis.
    Separates the 'which companies' judgment (LLM) from the
    'fetch and compute their data' logic (code).
    """
    tickers: list[str] = Field(
        min_length=3,
        max_length=10,
        description="Peer ticker symbols. Exactly 3-10 publicly traded companies.",
    )
    rationale: str = Field(
        description="One sentence: why these peers were selected (same sector, size, business model)."
    )


class DCFInputs(BaseModel):
    """Inputs for DCF calculation. LLM selects these, code computes the math.
    
    Note on FCF formula (P1.5 simplification):
    FCF = EBITDA × (1 - tax) - revenue × capex_pct - revenue × nwc_pct
    
    The explicit expansion:
    - projected_ebitda = projected_revenue × ebitda_margin
    - after_tax_ebitda = projected_ebitda × (1 - tax_rate)
    - capex = projected_revenue × capex_pct_revenue
    - nwc_change = projected_revenue × nwc_pct_revenue
    - fcf = after_tax_ebitda - capex - nwc_change
    
    This over-taxes by not deducting D&A before tax. Acceptable because yfinance
    doesn't provide D&A separately. When FMP is added (P2a), add a `depreciation`
    field and switch to: FCF = (EBITDA - D&A)(1-t) + D&A - Capex - ΔNWC.
    """
    revenue_base: float = Field(description="Base year revenue in USD")
    revenue_growth_rates: list[float] = Field(min_length=1, description="Projected annual growth rates as decimals")
    ebitda_margin: float = Field(ge=0, le=1, description="Projected EBITDA margin")
    capex_pct_revenue: float = Field(ge=0, le=1, description="Capex as % of revenue")
    # NWC change can be negative (releasing working capital)
    nwc_pct_revenue: float = Field(ge=-0.2, le=0.5, description="Net working capital change as % of revenue, negative = release")
    tax_rate: float = Field(ge=0, le=1, default=0.21)
    
    # WACC inputs
    risk_free_rate: float = Field(ge=0, le=0.15)
    beta: float = Field(ge=0, le=5)
    equity_risk_premium: float = Field(ge=0, le=0.15)
    cost_of_debt: float = Field(ge=0, le=0.20)
    debt_ratio: float = Field(ge=0, le=1, description="Debt / (Debt + Equity)")
    
    # Terminal value
    terminal_growth_rate: float = Field(ge=0, le=0.05, description="Long-term growth rate")
    
    shares_outstanding: float = Field(gt=0)
    net_debt: float = Field(description="Total debt - cash. Negative if net cash.")


class DCFResult(BaseModel):
    """DCF valuation output. All numbers computed by code, not LLM."""
    # WACC
    cost_of_equity: float | None  # None when wacc_override was used
    wacc: float
    
    # Projections (each list has len = projection_years)
    projection_years: int
    projected_revenue: list[float]
    projected_ebitda: list[float]
    projected_fcf: list[float]
    
    # Terminal value
    terminal_value: float
    pv_terminal: float  # present value of terminal value
    
    # Valuation
    pv_fcf_total: float  # sum of PV of projected FCFs
    enterprise_value: float  # pv_fcf_total + pv_terminal
    equity_value: float  # enterprise_value - net_debt
    implied_price: float  # equity_value / shares_outstanding
    
    # Sensitivity (WACC × terminal_growth grid)
    # Keys: "wacc_values" (list[float]), "tg_values" (list[float]),
    #        "implied_prices" (list[list[float | None]] — 2D grid, rows=wacc, cols=tg; None where tg >= wacc)
    sensitivity_table: dict[str, list] | None = None
    
    # Inputs used (for reproducibility)
    inputs: DCFInputs


class ThesisResult(BaseModel):
    """Investment thesis. LLM provides judgment, code validates structure."""
    recommendation: str = Field(description="Buy/Hold/Sell")
    price_target: float = Field(gt=0)
    price_target_basis: str  # e.g. "DCF base case" or "peer median EV/EBITDA"
    catalysts: list[str] = Field(min_length=1)
    risks: list[str] = Field(min_length=1)
    narrative: str  # LLM-written thesis narrative


class StepOutput(BaseModel):

    Note: `structured` uses `Any` because Pydantic cannot reconstruct concrete

    PipelineResult is in-memory only in P1.5 — if JSON roundtrip is needed later,
    switch to a discriminated union or use model_dump/model_validate per type.
    """
    text: str  # LLM narrative, used in final report
    structured: Any = None  # typed model at runtime, used by subsequent steps
```

### File 32: `finagent/engine/compute/wacc.py`

**Purpose**: WACC calculation. Pure function, deterministic, no LLM.

**What this code does that raw LLM cannot**: Produces the exact same WACC every time for the same inputs. LLM might round differently, use wrong formula, or hallucinate numbers.

**Also create**: `finagent/engine/compute/__init__.py`

```python
def calculate_wacc(
    risk_free_rate: float,
    beta: float,
    equity_risk_premium: float,
    cost_of_debt: float,
    tax_rate: float,
    debt_ratio: float,
) -> tuple[float, float]:
    """Calculate Weighted Average Cost of Capital.
    
    Returns:
        (cost_of_equity, wacc)
    
    Formula:
        Cost of Equity = Risk-Free Rate + Beta × Equity Risk Premium  (CAPM)
        WACC = E/(D+E) × Cost of Equity + D/(D+E) × Cost of Debt × (1 - Tax Rate)
    """
    cost_of_equity = risk_free_rate + beta * equity_risk_premium
    equity_ratio = 1 - debt_ratio
    after_tax_debt = cost_of_debt * (1 - tax_rate)
    wacc = equity_ratio * cost_of_equity + debt_ratio * after_tax_debt
    return cost_of_equity, wacc
```

**Formula source**: CAPM (Sharpe, 1964; Lintner, 1965). WACC definition per CFA Institute Level II curriculum and Damodaran, *Investment Valuation* (3rd ed., 2012), Chapter 8. The hand-calculated test value below must match independently — it is not derived from the code.

**Tests** (`tests/unit/test_wacc.py`):
- Hand-calculated example: risk_free_rate=0.04, beta=1.2, equity_risk_premium=0.05, cost_of_debt=0.04, tax_rate=0.21, debt_ratio=0.3
  - CoE = 0.04 + 1.2 × 0.05 = 0.10
  - WACC = 0.7 × 0.10 + 0.3 × 0.04 × (1 − 0.21) = 0.07 + 0.00948 = 0.07948
  - Assert `abs(wacc − 0.07948) < 1e-6`
- All-equity company (debt_ratio=0): wacc == cost_of_equity
- High leverage (debt_ratio=0.8): wacc drops due to tax shield
- Edge: debt_ratio=0 → no debt component
- Edge: beta=0 → cost_of_equity = risk_free_rate

### File 33: `finagent/engine/compute/dcf.py`

**Purpose**: DCF valuation calculation. Pure function, deterministic, no LLM.

**What this code does that raw LLM cannot**: Computes NPV, terminal value, and implied share price with exact math. Given identical inputs, always returns identical results. Includes sensitivity analysis.

```python
from finagent.engine.models.financial import DCFInputs, DCFResult
from finagent.engine.compute.wacc import calculate_wacc

def calculate_dcf(
    inputs: DCFInputs,
    wacc_override: float | None = None,
    tg_override: float | None = None,
) -> DCFResult:
    """Run a full DCF valuation from structured inputs.
    
    Args:
        inputs: DCF model parameters (LLM-selected, Pydantic-validated)
        wacc_override: If provided, use this WACC directly instead of calculating
                       from CAPM inputs. Used by sensitivity analysis.
        tg_override: If provided, override terminal_growth_rate from inputs.
                     Used by sensitivity analysis.
    
    Steps:
    1. Calculate WACC from inputs (or use wacc_override)
    2. Project revenue for N years using growth rates:
       revenue[0] = revenue_base × (1 + growth_rates[0])
       revenue[i] = revenue[i-1] × (1 + growth_rates[i])
    3. Project EBITDA = revenue × ebitda_margin
    4. Calculate FCF for each year:
       fcf = ebitda × (1 - tax_rate) - revenue × capex_pct_revenue - revenue × nwc_pct_revenue
       (Simplified: does not deduct D&A before tax. See DCFInputs docstring.)
    5. Discount each FCF to present value: PV = FCF / (1 + WACC)^n
       (Pure Python: sum(fcf / (1+wacc)**(i+1) for i, fcf in enumerate(fcfs)))
    6. Calculate terminal value: TV = final_FCF × (1 + g) / (WACC - g)
       where g = tg_override or inputs.terminal_growth_rate
       Raises ValueError if g >= WACC (perpetuity blows up).
    7. Discount terminal value to present: PV_TV = TV / (1 + WACC)^N
    8. Enterprise Value = sum(PV of FCFs) + PV of terminal value
    9. Equity Value = EV - net_debt
    10. Implied Price = Equity Value / shares_outstanding
    
    Returns:
        DCFResult with all computed values. cost_of_equity is None when wacc_override is used.
    """

def calculate_sensitivity(
    inputs: DCFInputs,
    wacc_range: list[float],       # e.g. [0.08, 0.09, 0.10]
    tg_range: list[float],         # e.g. [0.02, 0.025, 0.03]
) -> dict[str, list]:
    """Generate sensitivity table: implied price for each (WACC, terminal_growth) pair.
    
    Returns:
        {
            "wacc_values": [0.08, 0.09, 0.10],
            "tg_values": [0.02, 0.025, 0.03],
            "implied_prices": [           # 2D grid: rows=wacc, cols=tg
                [price_08_02, price_08_025, price_08_03],
                [price_09_02, price_09_025, price_09_03],
                [price_10_02, price_10_025, price_10_03],
            ]
        }
    
    For each combination, calls calculate_dcf(inputs, wacc_override=w, tg_override=g).
    Skips combinations where tg >= wacc (would raise ValueError) and uses None for those cells.
    """
    implied_prices = []
    for w in wacc_range:
        row = []
        for g in tg_range:
            if g >= w:
                row.append(None)  # perpetuity undefined
            else:
                result = calculate_dcf(inputs, wacc_override=w, tg_override=g)
                row.append(result.implied_price)
        implied_prices.append(row)
    return {
        "wacc_values": wacc_range,
        "tg_values": tg_range,
        "implied_prices": implied_prices,
    }
```

**Key details**:
- FCF = EBITDA × (1 - tax) - revenue × capex_pct - revenue × nwc_pct (simplified, no D&A — documented limitation)
- Terminal Value = Final FCF × (1 + terminal_growth) / (WACC - terminal_growth)
- PV = FCF / (1 + WACC)^n — pure Python, no numpy
- ValueError if terminal_growth_rate >= WACC
- **`wacc_override` parameter replaces the fragile "back-solve risk_free_rate" design** — sensitivity analysis passes WACC directly
- **`tg_override` parameter** allows overriding terminal growth rate for sensitivity
- `cost_of_equity` in DCFResult is `None` when `wacc_override` is used (CAPM was not computed)
- Sensitivity table uses `None` for cells where tg >= wacc (undefined perpetuity)

**Formula source**: NPV per Gordon & Shapiro (1956) and Brealey, Myers & Allen, *Principles of Corporate Finance* (13th ed.), Chapter 6. Terminal value (Gordon Growth Model): TV = FCF × (1+g) / (WACC − g). The hand-calculated expected values below are computed independently of the code — they serve as the external reference anchor.

```python
def calculate_ev(market_cap: float, total_debt: float, cash: float) -> float:
    """Enterprise Value = Market Cap + Total Debt - Cash"""
    return market_cap + total_debt - cash

def calculate_multiples(company: CompanyFinancials) -> CompanyFinancials:
    """Compute EV/EBITDA, EV/Revenue, P/E for a single company.
    
    Uses company.total_debt and company.total_cash for EV calculation.
    Fills derived fields on the model (frozen=False allows this).
    Returns the same object with computed fields set.

    - ev_ebitda = enterprise_value / ebitda (None if ebitda <= 0)
    - ev_revenue = enterprise_value / revenue (None if revenue <= 0)
    - pe_ratio = market_cap / net_income (None if net_income <= 0)
    """

def calculate_peer_statistics(comps: PeerComps) -> PeerComps:
```

### File 37: `finagent/engine/pipelines/base.py` (modify)

**Purpose**: Update Pipeline to support custom step execution logic and typed step results. This is the architectural change that makes P1.5 compute steps possible.

**What this code does that raw LLM cannot**: Stores structured data objects between steps, not just strings. Enables custom execution hooks (extract → compute → return typed result) that the default "just call agent.run()" cannot express.

**⚠️ Key architectural change: `execute_fn` and `validate_structured`**

P1.5 steps need custom logic beyond "call agent.run()":
- Step 1: agent.run() → extractor.extract_financial_data() → StepOutput
- Step 3: create param_agent(output_type=DCFInputs) → param_agent.run() → calculate_dcf() → StepOutput

The current PipelineStep has no hook for this. Adding two optional fields solves it:

```python
    Signature: async (agent, deps, prompt, structured_context, ticker) -> StepOutput | str

    Parameters:
        agent: The step's assigned sub-agent (may or may not be used inside the fn).
               Compute steps like Step 3 create their own param_agent internally.
```

```python
async def execute(self, deps: FinAgentDeps, ticker: str, **kwargs) -> PipelineResult:
    results = {}
    structured_results = {}
    
    for i, step in enumerate(self.steps):
        logger.info(f"Step {i+1}/{len(self.steps)}: {step.name}...")
        
        # 1. Gather data + build prompt (unchanged from P0)
        step_data = await self._gather_data(deps, step.required_data, ticker, results)
        methodology = ""
        if step.skill_section and deps.skill_runtime:
            skill = deps.skill_runtime.get(step.skill_section)
            if skill:
                methodology = skill.full_content
        prompt = self._build_step_prompt(step, step_data, methodology, structured_results)
        
        # 2. Execute: custom fn OR default agent.run()
        if step.execute_fn is not None:
            # P1.5 compute step — custom logic handles agent calls + code computation
            output = await step.execute_fn(step.agent, deps, prompt, structured_results, ticker)
        else:
            # P0/P1b default — just call agent.run()
            step_result = await step.agent.run(prompt, deps=deps)
            output = step_result.output
        
        # 3. Parse output: StepOutput or plain str
        if isinstance(output, StepOutput):
            results[step.name] = output.text
            if output.structured is not None:
                structured_results[step.name] = output.structured
                logger.info(f"Step '{step.name}' produced structured data: {type(output.structured).__name__}")
        elif isinstance(output, str):
            results[step.name] = output
        else:
            results[step.name] = str(output)
        
        # 4. Validate: typed validator (if available + structured data) OR text validator
        if step.validate_structured is not None and step.name in structured_results:
            validation = step.validate_structured(structured_results[step.name])
        else:
            validation = step.validate(results[step.name])
        
        # 5. Retry on validation failure (unchanged logic, but now routes correctly)
        if not validation.passed:
            for attempt in range(self.max_retries):
                if step.execute_fn is not None:
                    retry_prompt = (
                        f"Previous output failed validation: {validation.error}\n"
                        f"Fix the issues and try again.\n\n{results[step.name]}"
                    )
                    output = await step.execute_fn(step.agent, deps, retry_prompt, structured_results, ticker)
                else:
                    step_result = await step.agent.run(
                        f"Previous output failed validation: {validation.error}\n"
                        f"Fix the issues and try again.\n\n{results[step.name]}",
                        deps=deps,
                    )
                    output = step_result.output
                
                # Re-parse
                if isinstance(output, StepOutput):
                    results[step.name] = output.text
                    if output.structured is not None:
                        structured_results[step.name] = output.structured
                elif isinstance(output, str):
                    results[step.name] = output
                else:
                    results[step.name] = str(output)
                
                # Re-validate
                if step.validate_structured is not None and step.name in structured_results:
                    validation = step.validate_structured(structured_results[step.name])
                else:
                    validation = step.validate(results[step.name])
                
                if validation.passed:
                    break
            else:
                logger.warning(f"Pipeline step '{step.name}' failed validation after {self.max_retries} retries.")
        
        logger.info(f"Step {i+1}/{len(self.steps)}: {step.name} ✓")
    
    return PipelineResult(steps=results, structured_data=structured_results)

    steps: dict[str, str]  # text output per step, for report formatting
    structured_data: dict[str, Any] = Field(default_factory=dict)  # typed data per step

        return self.structured_data.get(step_name)
```

```python
async def _execute_financial_modeling(agent, deps, prompt, structured_context, ticker):

    param_agent = PydanticAgent(

        output_type=DCFInputs,
        instructions=(

def _build_sensitivity_ranges(dcf_result: DCFResult) -> tuple[list[float], list[float]]:
    """Build WACC and terminal growth ranges for sensitivity analysis.

    WACC range: 5 points, ±200bps around calculated WACC (step = 100bps).
    Terminal growth range: 5 points, ±100bps around base terminal growth (step = 50bps).

    Clamped: WACC ≥ 3%, terminal growth ≥ 0% and always < min(wacc_range).
    This ensures no cell in the sensitivity table has tg >= wacc (which would blow up TV).

    Example: WACC=9%, tg=2.5%
        wacc_range = [0.07, 0.08, 0.09, 0.10, 0.11]
        tg_range   = [0.015, 0.020, 0.025, 0.030, 0.035]
    """
    wacc = dcf_result.wacc
    tg = dcf_result.inputs.terminal_growth_rate

    wacc_range = [round(max(0.03, wacc - 0.02 + i * 0.01), 4) for i in range(5)]
    tg_candidates = [round(max(0.0, tg - 0.01 + i * 0.005), 4) for i in range(5)]

    # Ensure all tg values are strictly below the minimum WACC in the range
    min_wacc = min(wacc_range)
    tg_range = [g for g in tg_candidates if g < min_wacc]

    # If clamping left fewer than 2 points, fall back to safe defaults
    if len(tg_range) < 2:
        tg_range = [round(0.005 + i * 0.005, 4) for i in range(5) if 0.005 + i * 0.005 < min_wacc]

    return wacc_range, tg_range


# Pipeline construction
PipelineStep(
    name="data_collection",
    agent=agents["data"],
    validate=lambda out: validate_has_fields(out, ["revenue", "ebitda"]),
    validate_structured=validate_financial_data,
    execute_fn=_execute_data_collection,
    required_data=["financials", "price", "news"],
),
PipelineStep(
    name="peer_analysis",
    agent=agents["analysis"],
    validate=lambda out: validate_has_peers(out, min_peers=3),
    validate_structured=validate_peer_comps,
    execute_fn=_execute_peer_analysis,
),
PipelineStep(
    name="financial_modeling",
    agent=agents["modeling"],
    validate=lambda out: validate_is_non_empty(out),
    validate_structured=validate_dcf_result,
    execute_fn=_execute_financial_modeling,
    skill_section="dcf-model",
),
# Step 5 (report) — no execute_fn, pure LLM step
PipelineStep(
    name="report",
    agent=agents["report"],
    validate=lambda out: validate_report_format(out),
),
```

**Key details**:
- **`execute_fn` is optional** — steps without it use the P0 default `agent.run(prompt)`. This is fully backward compatible: all P0/P1b pipeline definitions work unchanged.
- **`validate_structured` is optional** — when set AND structured data exists, it's called INSTEAD OF the text validator. When absent, text validation still works.
- **execute_fn signature**: `async (agent, deps, prompt, structured_context, ticker) -> StepOutput | str`. The `agent` parameter is the step's assigned agent (may or may not be used — Step 3 creates its own param_agent). `structured_context` is the dict of structured data from previous steps. `ticker` is the stock symbol being analyzed (e.g. `"AAPL"`).
- **Retry logic routes correctly**: retries call execute_fn (if set) or agent.run() (default), then re-parse, then re-validate with the appropriate validator.
- **Logging added**: `logger.info(...)` for structured data type — satisfies acceptance criteria #1.
- `PipelineResult.structured_data` uses `dict[str, Any]` (not `dict[str, BaseModel]`) to avoid serialization issues.

### File 38: Update `equity_research.py` pipeline

**Purpose**: Rewire equity research pipeline to use extractors, compute functions, and typed models via File 37's `execute_fn` and `validate_structured` hooks.

**What this code does that raw LLM cannot**: Step 1 returns typed FinancialData (extracted by code from yfinance). Step 3 runs deterministic DCF (code computes WACC and NPV). Step 2's peer multiples are computed by code. LLM only selects parameters and writes narrative.

**Implementation pattern**: Each compute step defines an `async def _execute_*()` function (see File 37 examples) and wires it to PipelineStep via `execute_fn`. Pure-LLM steps (report) use no execute_fn.

**New step flow with execute_fn/validate_structured wiring**:

```
Step 1 (data_collection):
  - execute_fn: _execute_data_collection
    → data_agent fetches via yfinance
    → extractor.extract_financial_data() converts raw → FinancialData
  - Returns: StepOutput(text=formatted_data, structured=FinancialData)
  - validate_structured: validate_financial_data()
  - validate (text fallback): validate_has_fields(["revenue", "ebitda"])

Step 2 (peer_analysis):
  - execute_fn: _execute_peer_analysis
    → analysis_agent selects peers (LLM judgment)
    → Code fetches each peer's financials via data_layer + extract_company_financials()
    → compute/multiples.py: calculate_multiples() on each peer, then calculate_peer_statistics()
  - Returns: StepOutput(text=narrative, structured=PeerComps)
  - validate_structured: validate_peer_comps()
  - validate (text fallback): validate_has_peers(min_peers=3)

Step 3 (financial_modeling):
  - execute_fn: _execute_financial_modeling
    → Creates param_agent with output_type=DCFInputs (PydanticAI structured output)
    → param_agent.run() → typed DCFInputs
    → compute/dcf.py: calculate_dcf(dcf_inputs) → DCFResult
    → compute/dcf.py: calculate_sensitivity() → sensitivity table
  - Returns: StepOutput(text=narrative, structured=DCFResult)
  - validate_structured: validate_dcf_result()
  - validate (text fallback): validate_is_non_empty()

Step 4 (thesis):
  - execute_fn: _execute_thesis
    → synthesis_agent writes thesis using structured data from steps 1-3 (FinancialData, PeerComps, DCFResult available via structured_context)
    → Uses output_type=ThesisResult for structured output
  - Returns: StepOutput(text=narrative, structured=ThesisResult)
  - validate_structured: validate_thesis()
  - validate (text fallback): validate_has_thesis()

Step 5 (report):
  - execute_fn: None (default agent.run() — pure LLM step)
  - report_agent assembles final report using structured data + narratives from _build_step_prompt
  - Returns: str (final Markdown report, includes code-computed tables from structured_context)
  - validate_structured: None
  - validate: validate_report_format()
```

**Tests**:
- Step 1 produces FinancialData model in structured_data
- Step 3 with mocked DCFInputs → deterministic DCFResult
- Same mocked inputs → same DCFResult (reproducibility)
- Validators catch bad data (negative WACC, too few peers, etc.)
- Step 5 (report) uses no execute_fn — backward compat with P0/P1b behavior

```python
class TestNumericalCorrectness:
    """Hand-verified calculations. If these fail, the math is wrong."""
    
    def test_wacc_hand_calculated(self):
        """rf=4%, beta=1.2, erp=5%, cod=4%, tax=21%, D/(D+E)=30%
        CoE = 4% + 1.2 × 5% = 10%
        WACC = 70% × 10% + 30% × 4% × (1-21%) = 7% + 0.948% = 7.948%"""
        coe, wacc = calculate_wacc(0.04, 1.2, 0.05, 0.04, 0.21, 0.3)
        assert abs(coe - 0.10) < 1e-10
        assert abs(wacc - 0.07948) < 1e-6
    
    def test_ev_hand_calculated(self):
        assert calculate_ev(1000, 200, 50) == 1150
    
    def test_fcf_formula_explicit(self):
        """Verify FCF = EBITDA*(1-tax) - revenue*capex_pct - revenue*nwc_pct"""
        inputs = DCFInputs(
            revenue_base=100_000_000_000,

            debt_ratio=0.1,
            terminal_growth_rate=0.025,
            shares_outstanding=1_000_000_000,
            net_debt=10_000_000_000,
        )
        result = calculate_dcf(inputs)
        
        # Year 1: revenue = 100B * 1.05 = 105B
        expected_revenue = 100_000_000_000 * 1.05
        assert abs(result.projected_revenue[0] - expected_revenue) < 1
        
        # EBITDA = 105B * 0.35 = 36.75B

        expected_fcf = expected_ebitda * (1 - 0.21) - expected_revenue * 0.05 - expected_revenue * 0.02
        assert abs(result.projected_fcf[0] - expected_fcf) < 1
```
