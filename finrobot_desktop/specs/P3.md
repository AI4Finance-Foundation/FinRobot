# P3 — 从壳子到产品（Streaming + SDK + 数据验证 + 模型路由）

> **For agentic workers:** Use superpowers:subagent-driven-development to implement task-by-task. Mark each checkbox when done.

**Goal:** 让 FinAgent 从"结构完整但不好用"变成"开箱即用"。当前的问题：CLI 跑 pipeline 要等 30-120 秒没有任何输出、没有 Python SDK 只能通过 CLI 使用、所有步骤用同一个模型（贵且慢）、多数据源不做交叉验证。

**核心原则：** 每个 Track 独立可交付、独立可测试。不依赖前序 Track 完成。

**What code does that LLM cannot:**
- 实时 SSE 事件流（LLM 不能向客户端推送进度事件）
- 多源数据交叉验证（LLM 不会同时调两个 API 然后比较数字）
- 模型路由策略（LLM 不能在运行时切换自己的后端）
- 类型安全的 SDK 入口（LLM 不能提供 IDE 自动补全和类型检查）

**Approved dependencies:** 无新增依赖。StreamingResponse 来自 Starlette（FastAPI 已依赖）。

### Task 1: Pipeline progress callback

**File:** `finagent/engine/pipelines/base.py` (modify)

**What this code does that raw LLM cannot:** 实时进度推送 — LLM 不能在生成过程中向客户端发送结构化事件。

在 `Pipeline` 和 `Pipeline.execute()` 中增加回调机制。不改变现有签名的返回值，通过可选参数注入。

```python
from typing import Protocol
import time

class ProgressCallback(Protocol):
    """Called at start/end of each pipeline step."""
    async def on_step_start(self, step_index: int, total: int, step_name: str) -> None: ...
    async def on_step_end(self, step_index: int, total: int, step_name: str, duration_s: float) -> None: ...
    async def on_step_retry(self, step_index: int, step_name: str, attempt: int, error: str) -> None: ...

@dataclass
class Pipeline:
    steps: list[PipelineStep]
    max_retries: int = 3

    async def execute(
        self,
        deps: "FinAgentDeps",
        ticker: str,
        progress: ProgressCallback | None = None,  # NEW — backwards compatible
        **kwargs,
    ) -> "PipelineResult":
        ...
        for i, step in enumerate(self.steps, start=1):
            if progress:
                await progress.on_step_start(i, total, step.name)

            t0 = time.monotonic()
            validation_error = await self._run_step(
                step, deps, prompt, ticker, results, structured_results,
                progress=progress,  # pass through for on_step_retry
            )
            elapsed = time.monotonic() - t0

            if progress:
                await progress.on_step_end(i, total, step.name, elapsed)
            ...
```

**关键约束：**
- `progress=None` 时行为完全不变（向后兼容）
- `ProgressCallback` 是 Protocol，不是 ABC — 任何实现 3 个方法的对象都行
- `on_step_retry` 在 `_run_step` 内部的 retry 循环中调用
- `_run_step` 签名需要加 `progress: ProgressCallback | None = None` 参数，从 `execute()` 传入。在 retry 循环的 `logger.warning(...)` 之后加 `if progress: await progress.on_step_retry(...)` 调用

### Task 3: Server SSE endpoint

**File:** `finagent/server.py` (modify)

新增 `/api/pipeline/stream/{pipeline_type}/{ticker}` 端点，返回 SSE 事件流。

**关键修复（vs 初版 spec）：** `event_stream()` 必须用 `try/finally` 确保客户端断开时 task 被清理，否则 task 泄漏 + 异常丢失。

```python
from starlette.responses import StreamingResponse, JSONResponse
import json

# Module-level pipeline factory map (不在每次请求时 import)
_PIPELINE_FACTORIES: dict | None = None

def _get_pipeline_factories() -> dict:
    """Lazily load pipeline factories. Called once, cached."""
    global _PIPELINE_FACTORIES
    if _PIPELINE_FACTORIES is not None:
        return _PIPELINE_FACTORIES
    from finagent.engine.pipelines.equity_research import create_equity_research_pipeline
    from finagent.engine.pipelines.comps import create_comps_pipeline
    from finagent.engine.pipelines.dcf import create_dcf_pipeline
    from finagent.engine.pipelines.lbo import create_lbo_pipeline
    from finagent.engine.pipelines.earnings_analysis import create_earnings_analysis_pipeline
    from finagent.engine.pipelines.ic_memo import create_ic_memo_pipeline
    _PIPELINE_FACTORIES = {
        "research": create_equity_research_pipeline,
        "comps": create_comps_pipeline,
        "dcf": create_dcf_pipeline,
        "lbo": create_lbo_pipeline,
        "earnings": create_earnings_analysis_pipeline,
        "ic-memo": create_ic_memo_pipeline,
    }
    return _PIPELINE_FACTORIES


@app.get("/api/pipeline/stream/{pipeline_type}/{ticker}")
async def pipeline_stream(pipeline_type: str, ticker: str, request: Request):
    """Stream pipeline progress as Server-Sent Events."""
    import asyncio

    factories = _get_pipeline_factories()
    if pipeline_type not in factories:
        return JSONResponse(
            status_code=400,
            content={"error": f"Invalid pipeline: {pipeline_type}. Valid: {list(factories)}"},
        )

    queue: asyncio.Queue = asyncio.Queue()

    class SseProgress:
        async def on_step_start(self, i, total, name):
            await queue.put({"event": "step_start", "step": i, "total": total, "name": name})
        async def on_step_end(self, i, total, name, dur):
            await queue.put({"event": "step_end", "step": i, "total": total, "name": name, "duration": round(dur, 1)})
        async def on_step_retry(self, i, name, attempt, err):
            await queue.put({"event": "step_retry", "step": i, "name": name, "attempt": attempt})

    async def run_pipeline():
        try:
            deps = request.app.state.deps
            from finagent.engine.agents.factory import create_sub_agents
            sub_agents = create_sub_agents(deps.settings, skill_registry=deps.skill_runtime)
            pipeline = factories[pipeline_type](sub_agents)
            result = await pipeline.execute(deps, ticker, progress=SseProgress())
            deps.report_cache[ticker.upper()] = build_report_context(ticker, result)
            await queue.put({"event": "complete", "summary": result.format_summary()[:2000]})
        except Exception as e:
            await queue.put({"event": "error", "message": str(e)[:500]})
        finally:
            await queue.put(None)  # sentinel

    async def event_stream():
        task = asyncio.create_task(run_pipeline())
        try:
            while True:
                msg = await queue.get()
                if msg is None:
                    break
                yield f"data: {json.dumps(msg)}\n\n"
            await task  # propagate exceptions from pipeline
        except (asyncio.CancelledError, GeneratorExit):
            task.cancel()
            try:
                await task
            except asyncio.CancelledError:
                pass

    return StreamingResponse(event_stream(), media_type="text/event-stream")
```

### Task 5: `finagent/sdk.py`

**File:** `finagent/sdk.py` (create)

**What this code does that raw LLM cannot:** 类型安全的公开 API + IDE 自动补全 + 资源生命周期管理。

**关键修复（vs 初版 spec）：**
1. `close()` 通过 `DataLayer.close()` 公开方法，不穿透 `_cache` 私有属性
2. 支持 `async with FinAgent() as agent:` context manager
3. sync 方法检测已有 event loop（Jupyter 兼容）— 如果已有 loop 则提示用 async API

```python
"""FinAgent Python SDK — programmatic access to all pipelines.

Usage:
    from finagent import FinAgent

    # Sync (scripts, CLI):
    agent = FinAgent()
    result = agent.research("AAPL")
    print(result.format_summary())

    # Async (Jupyter, FastAPI, async code):
    async with FinAgent() as agent:
        result = await agent.aresearch("AAPL")

    # Manual cleanup (if not using context manager):
    agent = FinAgent()
    try:
        result = agent.research("AAPL")
    finally:
        asyncio.run(agent.close())
"""
from __future__ import annotations

import asyncio
from typing import TYPE_CHECKING

from finagent.config import get_settings
from finagent.engine.data.cache import DataCache
from finagent.engine.data.layer import DataLayer
from finagent.engine.deps import FinAgentDeps
from finagent.engine.pipelines.base import PipelineResult

if TYPE_CHECKING:
    from finagent.engine.pipelines.base import ProgressCallback


class FinAgent:
    """High-level entry point for FinAgent pipelines.

    Args:
        model: Model name override (e.g. "anthropic:claude-sonnet-4-6").
        **kwargs: Forwarded to FinAgentSettings constructor.
    """

    def __init__(self, model: str | None = None, **kwargs) -> None:
        overrides = {}
        if model:
            overrides["model_name"] = model
        overrides.update(kwargs)
        self._settings = get_settings(**overrides)
        self._deps: FinAgentDeps | None = None
        self._sub_agents: dict | None = None
        self._loop: asyncio.AbstractEventLoop | None = None  # persistent loop for sync API

    # --- Context manager ---

    async def __aenter__(self) -> "FinAgent":
        return self

    async def __aexit__(self, exc_type, exc_val, exc_tb) -> None:
        await self.close()

    # --- Resource management ---

    def _ensure_deps(self) -> FinAgentDeps:
        """Lazily build deps + sub-agents on first pipeline call."""
        if self._deps is not None:
            return self._deps

        from pathlib import Path
        from finagent.engine.data.providers.yfinance_provider import YFinanceProvider
        from finagent.engine.data.providers.sec_provider import SECEdgarProvider
        from finagent.engine.skills.registry import SkillRegistry

        providers: list = []
        if self._settings.fmp_api_key:
            from finagent.engine.data.providers.fmp_provider import FMPProvider
            providers.append(FMPProvider(api_key=self._settings.fmp_api_key))
        if self._settings.finnhub_api_key:
            from finagent.engine.data.providers.finnhub_provider import FinnhubProvider
            providers.append(FinnhubProvider(api_key=self._settings.finnhub_api_key))
        providers.append(YFinanceProvider())
        providers.append(SECEdgarProvider(user_agent=self._settings.sec_user_agent))

        skills_path = Path(self._settings.skills_dir)
        registry = SkillRegistry(skills_path) if skills_path.exists() else None

        cache = DataCache(self._settings.cache_db_path)
        data_layer = DataLayer(providers=providers, cache=cache)
        self._deps = FinAgentDeps(
            data_layer=data_layer, settings=self._settings, skill_runtime=registry
        )

        from finagent.engine.agents.factory import create_sub_agents
        self._sub_agents = create_sub_agents(self._settings, skill_registry=registry)

        return self._deps

    def _get_sub_agents(self) -> dict:
        self._ensure_deps()
        return self._sub_agents

    # --- Sync API ---

    def _run_sync(self, coro_fn):
        """Run async coroutine factory synchronously.

        Takes a callable that RETURNS a coroutine (not the coroutine itself).
        This avoids creating an unawaited coroutine when raising RuntimeError
        in already-running event loop contexts (Jupyter, FastAPI, etc.).

        Uses a persistent event loop to avoid cross-loop resource issues:
        asyncio.run() creates a NEW loop each call, but DataCache holds an
        aiosqlite connection tied to the first loop. Reusing one loop avoids
        "attached to a different loop" errors on repeated sync calls.
        """
        try:
            asyncio.get_running_loop()
            raise RuntimeError(
                "FinAgent sync methods (research, dcf, etc.) cannot be called from an "
                "async context (Jupyter notebook, FastAPI handler, etc.). "
                "Use the async API instead: await agent.aresearch('AAPL')"
            )
        except RuntimeError as e:
            if "cannot be called from an async context" in str(e):
                raise
            pass  # No running loop — good, proceed

        # Reuse a single loop for the lifetime of this FinAgent instance
        if self._loop is None or self._loop.is_closed():
            self._loop = asyncio.new_event_loop()
        return self._loop.run_until_complete(coro_fn())

    def research(self, ticker: str, progress: "ProgressCallback | None" = None) -> PipelineResult:
        """Run equity research pipeline. Blocking. Use aresearch() in async contexts."""
        return self._run_sync(lambda: self.aresearch(ticker, progress=progress))

    def dcf(self, ticker: str, progress: "ProgressCallback | None" = None) -> PipelineResult:
        return self._run_sync(lambda: self.adcf(ticker, progress=progress))

    def comps(self, ticker: str, progress: "ProgressCallback | None" = None) -> PipelineResult:
        return self._run_sync(lambda: self.acomps(ticker, progress=progress))

    def lbo(self, ticker: str, progress: "ProgressCallback | None" = None) -> PipelineResult:
        return self._run_sync(lambda: self.albo(ticker, progress=progress))

    def earnings(self, ticker: str, progress: "ProgressCallback | None" = None) -> PipelineResult:
        return self._run_sync(lambda: self.aearnings(ticker, progress=progress))

    def ic_memo(self, ticker: str, progress: "ProgressCallback | None" = None) -> PipelineResult:
        return self._run_sync(lambda: self.aic_memo(ticker, progress=progress))

    # --- Async API ---

    async def aresearch(self, ticker: str, progress: "ProgressCallback | None" = None) -> PipelineResult:
        from finagent.engine.pipelines.equity_research import create_equity_research_pipeline
        pipeline = create_equity_research_pipeline(self._get_sub_agents())
        return await pipeline.execute(self._ensure_deps(), ticker, progress=progress)

    async def adcf(self, ticker: str, progress: "ProgressCallback | None" = None) -> PipelineResult:
        from finagent.engine.pipelines.dcf import create_dcf_pipeline
        pipeline = create_dcf_pipeline(self._get_sub_agents())
        return await pipeline.execute(self._ensure_deps(), ticker, progress=progress)

    async def acomps(self, ticker: str, progress: "ProgressCallback | None" = None) -> PipelineResult:
        from finagent.engine.pipelines.comps import create_comps_pipeline
        pipeline = create_comps_pipeline(self._get_sub_agents())
        return await pipeline.execute(self._ensure_deps(), ticker, progress=progress)

    async def albo(self, ticker: str, progress: "ProgressCallback | None" = None) -> PipelineResult:
        from finagent.engine.pipelines.lbo import create_lbo_pipeline
        pipeline = create_lbo_pipeline(self._get_sub_agents())
        return await pipeline.execute(self._ensure_deps(), ticker, progress=progress)

    async def aearnings(self, ticker: str, progress: "ProgressCallback | None" = None) -> PipelineResult:
        from finagent.engine.pipelines.earnings_analysis import create_earnings_analysis_pipeline
        pipeline = create_earnings_analysis_pipeline(self._get_sub_agents())
        return await pipeline.execute(self._ensure_deps(), ticker, progress=progress)

    async def aic_memo(self, ticker: str, progress: "ProgressCallback | None" = None) -> PipelineResult:
        from finagent.engine.pipelines.ic_memo import create_ic_memo_pipeline
        pipeline = create_ic_memo_pipeline(self._get_sub_agents())
        return await pipeline.execute(self._ensure_deps(), ticker, progress=progress)

    async def close(self) -> None:
        """Close data cache connection and event loop. Safe to call multiple times."""
        if self._deps:
            await self._deps.data_layer.close()
        if self._loop and not self._loop.is_closed():
            self._loop.close()
            self._loop = None
```

### 问题

### Task 8: `finagent/engine/data/validator.py`

**File:** `finagent/engine/data/validator.py` (create)

**What this code does that raw LLM cannot:** 确定性数值比较 — 硬阈值判断两个数据源的偏差，LLM 不会自动对比两个 API 的返回值。

**重要限制：** 此验证器仅适用于 `data_type="financials"`。`price` 和 `news` 数据类型的字段结构不同，不在交叉验证范围内。

```python
"""Cross-provider data validation for financials data.

Thresholds (conservative):
- Revenue, EBITDA, net_income: 15% relative tolerance
  Why: FMP reports TTM vs yfinance may report latest fiscal year. 15% covers
  one-quarter timing difference for most companies.
- Market cap: 5% — real-time vs delayed, should still be close
- Margins: 10 percentage points absolute
"""
from finagent.engine.data.interface import DataResult

_RELATIVE_FIELDS = {
    "revenue": 0.15,
    "ebitda": 0.15,
    "net_income": 0.15,
    "market_cap": 0.05,
    "total_debt": 0.15,
    "total_cash": 0.15,
}

_ABSOLUTE_FIELDS = {
    "gross_margin": 0.10,       # 10pp
    "operating_margin": 0.10,
}


def cross_validate(primary: DataResult, secondary: DataResult) -> list[str]:
    """Compare two financials DataResults for the same ticker.

    Returns list of human-readable warning strings for any discrepancies.
    Empty list = data agrees within tolerances.

    Only checks fields present in BOTH results. Missing fields are not flagged
    (that's the extractor's job).
    """
    warnings: list[str] = []
    p, s = primary.data, secondary.data

    for field, tolerance in _RELATIVE_FIELDS.items():
        pv, sv = p.get(field), s.get(field)
        if pv is None or sv is None:
            continue
        if not isinstance(pv, (int, float)) or not isinstance(sv, (int, float)):
            continue
        if pv == 0 and sv == 0:
            continue
        denominator = max(abs(pv), abs(sv))
        if denominator == 0:
            continue
        rel_diff = abs(pv - sv) / denominator
        if rel_diff > tolerance:
            warnings.append(
                f"Data discrepancy: {field} differs by {rel_diff:.0%} "
                f"({primary.provider}: {pv:,.0f} vs {secondary.provider}: {sv:,.0f}). "
                f"Threshold: {tolerance:.0%}."
            )

    for field, tolerance in _ABSOLUTE_FIELDS.items():
        pv, sv = p.get(field), s.get(field)
        if pv is None or sv is None:
            continue
        if not isinstance(pv, (int, float)) or not isinstance(sv, (int, float)):
            continue
        abs_diff = abs(pv - sv)
        if abs_diff > tolerance:
            warnings.append(
                f"Data discrepancy: {field} differs by {abs_diff:.1%} "
                f"({primary.provider}: {pv:.1%} vs {secondary.provider}: {sv:.1%}). "
                f"Threshold: {tolerance:.0%}pp."
            )

    return warnings
```

### Task 9: DataLayer 集成

**File:** `finagent/engine/data/layer.py` (modify)

在 `fetch()` 中，当第一个 provider 成功后，**同步尝试第二个 provider** 进行交叉验证。这会增加延迟（~1-2 秒），但数据正确性比速度重要。

**设计决策：同步而非异步。** 虽然 `asyncio.create_task` 可以不阻塞，但交叉验证的 warning 必须附加到返回值上。如果异步执行，warning 无法及时附加，用户拿到的结果没有 discrepancy 提示。因此选择同步等待第二个 provider，代价是额外 1-2 秒延迟。

**仅对 `data_type="financials"` 做交叉验证。** `price` 和 `news` 不做。

```python
from finagent.engine.data.types import DataType

async def fetch(self, data_type: str | DataType, ticker: str, **kwargs) -> DataResult:
    ...
    # 2. Try each provider in order
    primary_result = None
    for provider in self._providers:
        if data_type not in provider.capabilities():
            continue
        try:
            result = await provider.fetch(ticker, data_type, **kwargs)
            if primary_result is None:
                primary_result = result
                # Only cross-validate financials, and only if more providers exist
                if data_type == DataType.FINANCIALS:
                    continue  # try one more provider
                else:
                    break  # non-financials: first success is enough
            else:
                # Second provider succeeded — cross-validate
                from finagent.engine.data.validator import cross_validate
                discrepancies = cross_validate(primary_result, result)
                if discrepancies:
                    primary_result = primary_result.model_copy(
                        update={"warnings": primary_result.warnings + discrepancies}
                    )
                break  # two providers checked, done
        except ProviderError as e:
            logger.warning(f"Provider '{provider.name}' failed for {ticker}/{data_type}: {e}")
            continue

    if primary_result is not None:
        await self._cache.set(data_type, ticker, primary_result)
        return primary_result
    ...
```

## Track 5: Prompt 优化

### 问题

`Pipeline._gather_data()` 在 `required_data=[]` 时把**所有前序步骤的完整文本**拼进 prompt。5 步 pipeline 的第 5 步会收到 ~2000 字的前序输出，其中大部分对当前步骤没用。

### 安全性分析

**风险：** 如果某些 pipeline 步骤输出是纯文本（没有 `StepOutput.structured`），它们的信息只存在于 `previous_results` 文本中。如果 `_gather_data` 只传最后一步的文本，前面纯文本步骤的信息会完全丢失。

**验证结果：** equity_research pipeline 的 step 1 (data_collection) 和 step 4 (thesis) 输出可能是纯文本。DCF pipeline 的 step 4 (sensitivity) 也可能是纯文本。这些步骤的信息不在 `structured_context` 中。

**安全策略：** 改为传最近 2 步的文本（而非 1 步），并在 `_build_step_prompt` 中为所有 `previous_results` 生成一行摘要（step 名 + 字数），让 LLM 知道前面有哪些步骤。

### Task 13: Compact context mode

**File:** `finagent/engine/pipelines/base.py` (modify)

```python
async def _gather_data(self, deps, required_data, ticker, previous_results):
    if not required_data:
        if not previous_results:
            return ""
        # Pass last 2 steps' full text + 1-line summaries of earlier steps
        keys = list(previous_results.keys())
        parts = []
        # Summaries of older steps (so LLM knows they exist)
        for name in keys[:-2]:
            text = previous_results[name]
            word_count = len(text.split())
            parts.append(f"[Previous: {name} — {word_count} words, see structured_context for data]")
        # Full text of last 2 steps
        for name in keys[-2:]:
            parts.append(f"=== {name} ===\n{previous_results[name]}")
        return "\n\n".join(parts)
    ...
```

**Why last 2 instead of last 1:** Step N often needs context from both Step N-1 (direct input) and Step N-2 (e.g., thesis step needs both financial_modeling and peer_analysis). Passing 2 steps covers this common pattern while still reducing prompt size by ~40-60% for 5+ step pipelines.
