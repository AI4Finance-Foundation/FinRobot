# P6 — FinRobot 能力基线补齐

> **来源：** 外部审计确认 FinAgent 覆盖率 62.5%（9/23 图表 + 催化剂空壳 + SEC 仅 MD&A）。
> **目标：** 补齐到 100% 覆盖，且每个模块做得比 FinRobot 更好。
> **原则：** FinRobot 的能力是下限，不是上限。

---

## Do NOT

- 不引入 `unstructured.io`（100MB+ 依赖，FinAgent 用轻量正则方案）
- 不引入 `sklearn`（FinRobot 的 TOC DBSCAN 聚类过度工程化）
- 不做 ML 概率模型（催化剂概率用 LLM 判断 + 确定性校准，不训练模型）
- 不抄 FinRobot 代码（它是 AutoGen 0.2 + 全局状态，架构是反面教材）
- 新增图表**必须**遵循 `base.py` 的 `ChartDataPoint` + `ChartConfig` + `_num()` 模式

## Track B — 催化剂分析重建

### 设计原则

FinRobot 的催化剂分析用 410 行硬编码 keyword matching + 固定概率表。**FinAgent 不抄这个方案**——LLM 做分类 + 确定性代码做排序/过滤/加权，这是 FinAgent 的核心架构优势。

关键设计决策：
- **news.py 已有 7 类分类和 sentiment**，催化剂分析应该是 news 的下游，不是并行的独立模块
- **概率不硬编码**——由 LLM 在 pipeline context 中判断（已经有 CatalystEvent.probability 字段）
- **impact_score 不按事件类型固定**——由 LLM 结合公司/行业/时机综合判断

```python
# 保留

def filter_by_impact(events: list[CatalystEvent], min_score: int = 1, sentiment: str | None = None) -> list[CatalystEvent]:

# 新增
CATALYST_CATEGORIES: dict[str, str] = {
    "product_launch": "New product, service launch, or major feature release",
    "earnings": "Quarterly earnings, guidance update, revenue warning",
    "regulatory": "FDA approval, antitrust, compliance, legal settlement",
    "acquisition": "M&A, partnership, strategic investment, divestiture",

def classify_catalyst_type(news_category: str) -> str:
    """Map news.py 7-category to catalyst 6-category.
    
    earnings → earnings
    product → product_launch
    regulatory → regulatory
    management → management
    analyst → market (analyst coverage change is a market dynamic)
    macro → market
    other → market
    """

def extract_catalysts_from_news(
    news_items: list[NewsItem],
    min_importance: int = 3,

    """Convert high-importance news items to CatalystEvent objects.

    This is deterministic conversion — no LLM call here.
    
    Mapping:
    - category → classify_catalyst_type()

    - headline → news.headline
    - reasoning → news.summary

def compute_expected_impact(events: list[CatalystEvent]) -> list[CatalystEvent]:
    """Compute expected_impact = impact_score × probability × sentiment_multiplier.
    
    sentiment_multiplier: positive=+1, negative=-1, neutral=0.
    Returns new list sorted by abs(expected_impact) descending.
    """

def summarize_catalyst_outlook(events: list[CatalystEvent]) -> dict:

            "top_negative": list[CatalystEvent],
```

**What this code does that LLM cannot：**
- `classify_catalyst_type()` — 确定性映射，不会因 prompt 变化而漂移
- `compute_expected_impact()` — 数学乘法 + 排序，LLM 不做算术
- `summarize_catalyst_outlook()` — 结构化汇总，保证字段完整性

```python
_ITEM_PATTERNS: dict[str, re.Pattern] = {
    "item_1_business": re.compile(
        r"(?i)item\s+1[.\s\u2014\u2013\-]+business", re.IGNORECASE

    ),

        r"(?i)item\s+8[.\s\u2014\u2013\-]+financial\s+statement", re.IGNORECASE
```
